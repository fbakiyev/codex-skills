# Workflow: Async Standup

## Trigger

Use during active sprint execution or when the user asks for delivery status.

## Agents

- `scrum-master`
- `project-manager`
- `context-steward`

## Steps

1. Read sprint backlog, latest handoffs, blockers, and validation artifacts.
2. Summarize done, next, blockers, and risk changes.
3. Escalate unresolved blockers to the right owner agent.
4. Update standup artifact.

## Outputs

- `.memory/projects/<project>/sprints/<sprint>/standups/YYYY-MM-DD.md`
- updated blockers when needed
