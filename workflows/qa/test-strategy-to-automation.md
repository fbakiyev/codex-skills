# Workflow: Test Strategy To Automation

## Trigger

Use when a feature, platform change, data pipeline, ML system, or security change needs test coverage.

## Agents

- `qa-strategist`
- `test-automation-engineer`
- specialized test agents as needed

## Steps

1. Translate acceptance criteria into risk-based test plan.
2. Choose test layers.
3. Implement or update tests.
4. Add CI gates only when reliable.
5. Record validation and gaps.

## Outputs

- test plan
- automated tests
- CI quality gate notes
- handoff
