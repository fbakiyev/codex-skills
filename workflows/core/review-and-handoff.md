# Workflow: Review And Handoff

## Trigger

Use for a consequential change requiring review or for an actual transfer of work.

## Steps

1. Review changed behavior and acceptance criteria with `technical-review` and relevant domain expertise.
2. Run proportionate validation and resolve actionable findings within the authorized scope.
3. Provide the result, verification evidence, and material limitations.
4. Use `artifact-handoff` if work is being transferred or a durable record was requested. Otherwise the completion response is sufficient.
5. Fix task failures within scope. Propose a reusable improvement when justified; invoke `skill-evolution-loop` only as part of authorized library maintenance.

## Outputs

Review findings, if any, and verification results. A separate handoff is conditional on the transfer requirement.
