# Workflow: ML System Delivery

## Trigger

Use for ML research moving toward production, model serving, feature pipelines, RAG systems, or evaluation gates.

## Agents

- `ml-research-engineer`
- `ml-engineer`
- `model-evaluation-engineer`
- `mlops-engineer`
- `feature-store-engineer` when features are involved

## Steps

1. Define problem, data, baseline, metric, and acceptance threshold.
2. Build or update model, features, or retrieval system.
3. Run evaluation and error analysis.
4. Document model card and eval report.
5. Define deployment, monitoring, and rollback.
6. Write handoff.

## Outputs

- model card
- eval report
- deployment and monitoring notes
- handoff
