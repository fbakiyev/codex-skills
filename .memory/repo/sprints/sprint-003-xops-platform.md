# Sprint 003: xOps Platform Pack

## Goal

Add platform and xOps skills, agents, workflows, templates, and validation for operational artifacts and secret-safe access maps.

## Scope

- Platform design, infrastructure provisioning, GitOps delivery, secrets/access mapping, runbook, observability, incident, backup/restore, and cost governance skills.
- xOps agents for platform, DevOps, SRE, GitOps, CloudOps, DevSecOps, DataOps, MLOps, DBOps, Observability, FinOps, Release, and Incident Command.
- xOps workflows for platform delivery, secret onboarding, incident response, and backup/restore.
- Operational templates for system design, deployment map, observability, backup/restore, security notes, incident report, and service catalog.
- Validation strengthened for xOps required templates and secret-safe access map.

## Definition Of Done

- xOps tasks have artifact-first DoD.
- Secret values are forbidden; secret references are first-class.
- Repository validation passes.
- Sprint is committed and pushed.

## Handoff

Next sprint should add domain packs for software engineering, data platform, ML/MLOps, QA/AQA, and security.
