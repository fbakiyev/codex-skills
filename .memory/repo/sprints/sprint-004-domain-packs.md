# Sprint 004: Domain Packs

## Goal

Add core domain coverage for engineering, data platform, ML/MLOps, QA/AQA, and security.

## Scope

- Software engineering skills and agents.
- Data platform skills and agents.
- ML/MLOps skills and agents.
- QA/AQA skills and agents.
- Security skills and agents.
- Domain workflows and templates for API contracts, tests, threat models, data contracts, model cards, evals, performance, and vulnerability triage.

## Definition Of Done

- Each required v1.0 domain has at least one workflow, several skills, and role agents.
- Domain artifacts are reusable across Agile and xOps delivery.
- Repository validation passes.
- Sprint is committed and pushed.

## Handoff

Next sprint should harden validation, add v1.0 manifest/status, update Russian README, and tag or mark release readiness.
