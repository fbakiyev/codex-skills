# Sprint 002: Agile Delivery Pack

## Goal

Add sprint-based delivery skills, agents, workflows, and templates.

## Scope

- Backlog management, sprint planning, async standup, review/retro, requirements analysis, system analysis, and Linear export skills.
- Delivery agents: portfolio manager, PO, PM, scrum master, BA, system analyst, data analyst, delivery reviewer.
- Agile workflows for refinement, planning, standup, review, and retro.
- Templates for standup, review, retro, requirements, system analysis, data analysis, and Linear export.

## Definition Of Done

- Delivery agents define responsibilities and artifacts.
- Agile skills use artifact-first workflows.
- Linear-ready metadata is represented without requiring Linear access.
- Repository validation passes.
- Sprint is committed and pushed.

## Handoff

Next sprint should add the xOps/platform pack with secret-safe access maps, runbooks, observability, backup/restore, and incident workflows.
