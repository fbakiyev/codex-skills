# Sprint 000: Repository Foundation

## Goal

Create the initial repository contract for a sprint-based Codex skills system.

## Scope

- Russian README.
- Future-agent instructions.
- Repository manifest.
- Core artifact templates.
- Structural validation script.

## Definition Of Done

- Repository has an explicit purpose and structure.
- Artifact templates exist for handoff, ADR, backlog, sprint brief, access map, runbook, and skill evolution.
- Validation script can run locally.
- Changes are committed and pushed to GitHub.

## Handoff

Next sprint should add the core operating-system skills and core agent roles.
