# Cloud Security Review

## Workflow

1. Identify accounts, projects, networks, identities, workloads, and data stores.
2. Review least privilege, network exposure, encryption, logging, and secret handling.
3. Check public access and cross-environment boundaries.
4. Document risks and remediation backlog.

## Guardrails

- Do not assume private by default.
- Do not weaken auditability for convenience.
