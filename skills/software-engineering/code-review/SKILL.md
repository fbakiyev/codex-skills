# Code Review

## Workflow

1. Inspect diff and related contracts.
2. Prioritize behavioral bugs and risk over style.
3. Check tests, validation, migrations, and artifacts.
4. Provide findings with severity, location, impact, and fix.
5. State when no blocking issues are found.

## Guardrails

- Do not bury findings after a long summary.
- Do not approve risky changes without validation evidence.
