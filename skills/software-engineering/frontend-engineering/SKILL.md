# Frontend Engineering

## Workflow

1. Inspect existing design system, routing, state, and component patterns.
2. Build the actual user workflow, not a marketing placeholder.
3. Keep controls ergonomic, responsive, accessible, and visually consistent.
4. Validate with build, tests, lint, and browser screenshots when practical.
5. Check mobile and desktop layout for overlap and broken text.

## Artifacts

- Handoff with screenshots or browser validation when UI changed.
- Test plan for important user flows.

## Guardrails

- Do not introduce unrelated visual redesigns.
- Do not leave primary flows unimplemented behind decorative UI.
