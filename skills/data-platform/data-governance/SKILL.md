# Data Governance

## Workflow

1. Identify data owner, steward, classification, consumers, and retention.
2. Document access rules and approval path.
3. Capture lineage and source of truth.
4. Review privacy and compliance constraints.
5. Update catalog and data contract.

## Guardrails

- Do not grant broad access by default.
- Do not document sensitive values; use access references.
