# Инструкции для современных моделей

Рекомендации для версии библиотеки `1.1.0`, сверены с документацией 11 сентября 2026 года. Здесь описано поведение навыков. Выбор модели и параметры API относятся к настройкам приложения.

## GPT-6 Astra

Официальное руководство рекомендует проверить доступные модели файлы инструкций: неоднозначное требование способно вызвать лишнюю остановку. Поэтому общие роли больше не требуют отдельный handoff после каждой задачи, а основные навыки различают обычное завершение, передачу работы и сопровождение библиотеки.

Самостоятельность ограничена согласованной задачей. Существенное уточнение не мешает выполнить независимую часть. Перед необходимым согласованием должен быть готов проверяемый результат. Параллельность полезна для самостоятельных частей работы; глубину проверки определяет риск изменения. Это применение рекомендаций к данной библиотеке, а не обещание одинакового поведения во всех средах. [Руководство GPT-6 Astra](https://developers.openai.com/api/docs/guides/latest-model#prompting-best-practices).

## GPT-5.6

Инструкции стоит сокращать по одной группе и сравнивать на прежних примерах. Сохраняйте правила, которые задают обязательный результат или предотвращают известную ошибку. В офисных навыках такими правилами стали сохранение условий документа, проверка знаменателей в таблице и разделение решений и предложений на встрече.

Краткость не должна вытеснять существенные факты, оговорки и следующий шаг. Поэтому формат результата задан для каждого вида работы. [Руководство GPT-5.6](https://developers.openai.com/api/docs/guides/latest-model?model=gpt-5.6#prompting-best-practices).

## Проверка совместимости

При смене модели используйте одинаковые исходные данные и сравнивайте готовые результаты с критериями в `evals/sample-tasks/`. Отдельно проверяйте выбор подходящего навыка и отказ от его применения к соседней задаче. Измерение времени и стоимости имеет смысл только при сопоставимом качестве.

Навык не включает API-режимы, инструменты или подключённые приложения. Параметры вроде reasoning и возможности параллельных вызовов проверяйте в документации конкретной среды; не переносите значения из API в конфигурацию Codex автоматически. [Миграция модели](https://developers.openai.com/api/docs/guides/latest-model#migration-quickstart).
