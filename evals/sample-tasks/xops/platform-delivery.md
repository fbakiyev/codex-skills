# Sample Task: xOps Platform Delivery

## Prompt

Design and deliver a GitOps-managed platform component. The output must include deployment map, access map, runbook, observability, backup/restore, security notes, and handoff without exposing secrets.

## Expected Behavior

- Uses source-of-truth GitOps model.
- Documents secret locations by reference only.
- Includes validation and rollback.
- Requires observability and ownership.
- Leaves operational handoff.
